The Atlas's own report tonight says **"auto-added its fifth sub-axis"** and **"Five
auto-additions now stand, none reviewed, none carrying a citation"**, under a five-row table.
The emission it published in the same run carries **six**:

    D.watch-labor      2026-08-24   monitoring: Labor, Society & Democratic Institutions residue
    E.watch-ai         2026-08-10   monitoring: AI Industry & Markets residue

`R.watch-federal` is real, it has `origin` set, it has `cites: []`, it has stood since
**2026-08-10 — 35 days** — and it is drawn on this sheet tonight in axis R's control row. It is
named in the Atlas's reports of 08-24, 08-26 and 09-02 and appears in **none** of the roll-calls
since. Our drift detector counts six. The parent counts five.

**The mechanism.** The parent's roll-call enumerates `weights["schema_log"]`, which has exactly
five entries and does not contain `R.watch-federal`. The log is written by the weekly review as
it adds; `R.watch-federal` was never written by the weekly review. Its own `origin` string says
so:

    "auto: weekly schema review 2026-08-10 - 19 unexplained events in 7 days; FOR AUGUST'S
     REVIEW. Carried from C at r5, which split C into C and R."

It entered the registry through the **r5 axis split**, which carried C's sub-axes onto the new R
and wrote no log entry because it was not the review adding anything. Note the tell: every
review-written origin uses an em dash, and this one — written by the carry-forward path — uses a
plain hyphen. Two code paths, one registry, one log.

The log is not wrong about itself. It is a faithful record of **what the emitter did**, and the
`existing` set that reads it (`nightly_update.py:380`) uses it correctly, to stop the review
re-proposing the same sub-axis every Monday. The defect is that a *count of what stands* was
built on it. A sub-axis that entered by any other route is invisible to every sentence derived
from the log — including the sentence whose entire purpose is to prompt the review.

**The rule: count the artefact, not the actor's diary.** A roll-call of what exists reads the
thing that exists. A log answers "what did I do", never "what is there"; the two agree only
while exactly one writer has ever written, and r5 was a second writer. This is the same family
as every defect this project has found — a surface reading a proxy for the quantity it claims to
report — and it is the third time the proxy has been a *record of an action* standing in for a
*state of the world*.

It also inverts tonight's known parent defect neatly. The key function
`"%s.watch-%s" % (ax, sec.lower().split(" ")[0])` collapses **two sections into one key**; the r5
split expanded **one cluster into two sub-axes** and the roll-call collapsed them back into one
row. Both directions, same night, same root: an identity built from something that is not the
thing.

Nothing to fix here. `axisNotes()` reads the registry and draws all six, so this sheet is the
surface telling the truth about `R.watch-federal` tonight. The parent's count is the parent's to
correct — logged here, not touched.
